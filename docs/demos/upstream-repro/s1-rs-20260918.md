# `s1-rs`: the examples that were blocked all day were never blocked by Rust

Typed System One decisions for Rust. Two examples, both offline against a `FakeClient`, no network
and no key. They sat unrun for the whole session behind an infrastructure story that turned out to be
the wrong story.

## What runs

```bash
docker run --platform linux/amd64 -v "$PWD":/w:ro -w /w --name s1run rust:1-slim \
  sh -c 'CARGO_TARGET_DIR=/tmp/t cargo run --quiet --example triage'
```

```
triage         billing queue
               frustration nearest=Annoyed expected=1.20
               urgent p=0.97

moderation     moderator queue, hint=Quarantine
               severity nearest=Mild expected=1.10
               not personal
```

Read-only mount, target directory inside the container, nothing written to the clone.

## The blocker was misdiagnosed twice before it was routed around

1. **"Local Rust builds are denied by construction."** True, and it is the *policy*, not the
   obstacle. The refusal message names RCH as the sanctioned path.
2. **"RCH refused: `critical_pressure=4`, no admissible workers."** Read as capacity, recorded in the
   README as such, and wrong. On retry the remote compile **succeeded** on `contabo-2` and returned
   **ELF binaries for an `aarch64-apple-darwin` host**: `RCH-E327`, a platform mismatch. Capacity was
   never the constraint.
3. **The actual shape:** the examples needed *a Linux toolchain and a Linux target*, which is a
   container, not a scheduler. Pane 3 found this route for `commit-miner` under the same error code,
   and it transfers directly because the binary never has to leave the container.

**Three descriptions of one blocker, two of them wrong, and the wrong ones were the ones written
down.** A blocker recorded at the wrong layer is worse than an open question, because it stops
people trying the thing that works.

## What the examples show about the API

The `triage` example declares its questions as Rust types: a `#[derive(Choice)]` enum with a
docstring per variant, a `#[derive(Score)]` enum for frustration, and a `#[derive(Questions)]`
struct binding them into one request. The answers come back as `nearest=Annoyed expected=1.20` and
`urgent p=0.97` — an ordinal with an expected value, and a probability, rather than text to parse.

That is the same shape this lane already relies on through the HTTP surface, expressed as a type
system: **the question is the schema, and the schema is checked at compile time.**

## No-claim

- These are the **shipped examples against a `FakeClient`**, scripted responses, not live calls.
  Nothing here measures Jev's judgment; it measures that the crate's typed surface compiles and
  produces the shapes its README claims.
- `cargo test` was **not** run — only the two examples. The crate's own suite is unmeasured here.
- The container route is a **workaround for a local policy and a platform mismatch**, not an
  endorsement of it as this fleet's build path. `RCH-E327` remains unfixed and is upstream of this
  repo.
- Two named containers are left behind by these invocations; the sanctioned cleanup flag is denied
  here, so they are noted rather than removed.
