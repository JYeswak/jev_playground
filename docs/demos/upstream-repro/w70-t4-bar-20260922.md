# T4 bar — pane 2 tool clones — 2026-09-22

Written before any live call in this wave. Model pin: `jev-1.13.0`. A clone that sends `jev-latest` fails the pin. Do not retune a threshold after seeing an answer.

Applies to: `jev-mcp`, `jev-review`, `jev-router`, `jev-codex-router`, `fast-jev-compaction`, `pi-subagents`.

Pass for the live call:

- The request names `jev-1.13.0`.
- The state is the clone's own example or fixture, not one written for this run.
- The process is alive after the call.
- The body is schema-valid for the question the clone asked, or the client throws and executes nothing.
- N is stated. If N is under 20, the receipt says smoke, not a certification, and makes no accuracy claim.
- Latency is stated per call. p50 and p95 are stated only when N is at least 5. Below that, they are not observable.
- Token usage is copied from the response when both counts are finite. Cost is not invented.

Fail:

- A missing key becomes a score.
- A malformed body is coerced into a choice.
- The host process exits.

Catalogues (`awesome-jev`, `awesome-jev-by-typesafe`, `upstream/typesafe-ai/skills`) do not take this bar. They run T1 and T3 only.
