# T4 bar — new clones — 2026-09-23

Written before any live call in this amendment. Model pin: `jev-1.13.0`. A request that sends `jev-latest` fails the pin. Do not retune a threshold after seeing an answer. Do not print a key.

Before any live call on labelled rows, run `node work/jev-prevalence-first/prevalence-check.mjs <rows> --truth <label>` and paste its three lines. If that exits 2 or 3, the live call is still allowed only as a smoke, and the receipt must say the prevalence class. No accuracy claim if N is under 20.

Pass for a live call:

- The request names `jev-1.13.0`.
- The state is the clone's own data or a public labelled set, not a set written to make Jev look good.
- N, latency, and token usage (when both counts are finite) are stated. Cost is not invented. p50 and p95 are stated only when N is at least 5.
- A missing key or a malformed body does not become a score. The host survives, except where the clone's own design exits the process and the receipt says so.

Hard limits, failing these is a failed run:

- `agent-desktop` never acts on the real desktop. Live Jev only through a no-execute path. If none exists, T4 is NOT-RUN.
- `prism-liquidity-agent` is backtest or paper only. No wallet, no order path.
- `jev-drone` is MuJoCo only. No hardware.
- `typesafe-mario` runs live only if a ROM is already on disk. Do not download one.
- `jev-trader` is never run.

T6 incumbent, where the class profile requires it: the same state and questions through `upstream/typesafe-ai/system-one-adapter-python` against one LLM. If the adapter cannot be loaded, T6 is NOT-RUN with the command, the error, the file:line, and a second route.
