do not get to ignore my own routing because I like the headline
number. The distinction, stated plainly: the ambiguous bar guards
*pattern quality* (can the classifier see the space?), while the
failure rule guards *surface existence* (is there anything to gate?).

conservative design, in a fleet where eval is predominantly read-side
compute (probes, judgments, completions). That is a known over-
conservative bucket, not an unseen region of the space: I can name
exactly what fills it and why. So the HEALTHY verdict stands for what
was asked (surface exists), and the pattern debt is carried explicitly
into the labels phase as a precondition: split eval by callee shape
or accept the bucket, but do not run gold labels through a classifier
whose biggest bucket means "didn't look."

Sharpening cannot flip this verdict in the thin direction — moving
eval-read shapes to reversible only shrinks ambiguous, and the
irreversible flags (write/edit/mutating-bash, all precise positives)
do not move. The debt is real work, but it is bounded work with no
falsification leverage left in it.
