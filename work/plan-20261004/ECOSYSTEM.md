# Classifier ecosystem: where each technique earns its place (evidence map, 2026-10-04)

Purpose: the basis for a public README section on how this project chooses, tests and applies classifier
techniques. Jev is one technique in this ecosystem, not the frame. Read-only research: no model calls and no
`br` were run for this file. The only computation was a $0 re-read of committed rows, marked `[RECOMPUTED]`
(Python over the named file, no writes).

**Citation rules**
- `path:line` or `path` (field) = a file in this repo. **NE** = `NEGATIVE_EVIDENCE.md`.
- `†` = the file is under `var/agent-tmp/` and is gitignored scratch. Commit it as a receipt (or drop the
  number) before the README cites it publicly.
- URLs = external evidence. arXiv numbers come from the abstract unless a table is named.
- `INFERENCE` = judgement, not a measurement. `UNMEASURED` = no receipt exists here.
- Our receipts outrank the literature on claims about our data. The literature fills cells where we have no
  receipt.

**Unit costs used throughout**
- Hosted Jev (`jev-1.13.0`): $0.042 per million input tokens, output free. Measured short-state cost per 1,000
  answers: $0.0158 (Score), $0.0162 (Choice), $0.0287 (Noul) (`docs/LEDGER.md:166`).
- Long states cost more. The omp `find` passage ranker averages ~4,888 input tokens per call, $0.000205 per
  call, i.e. ~$0.205 per 1,000 (`work/plan-20261004/specs/advanced-literature.md:34`).
- General LLM (Claude Haiku 4.5 list price, same rows): $0.9484 / $1.4287 / $0.9475 per 1,000, 33-88x Jev
  (`docs/LEDGER.md:166`).
- Local models (Clef-Flash, Kev-4B, Ollama nimble/tev1, encoders): $0 marginal spend. Cost is latency, GPU
  contention on one Mac, and labels.

## 0. Five findings that should shape the README

1. **The cheapest instrument often wins, and we have receipts for it.** A regex beat Jev on bundled acceptance
   boxes (F1 .588 vs .176, †`var/agent-tmp/dogfood/beadpass/out-pass1.jsonl` scored against
   †`labelled.jsonl`, `[RECOMPUTED]`). A keyword rule beat Jev on tool-call risk triage, 58/60 vs 52/60. A regex
   beat it on phishing, 91.65% vs 62.98% (`docs/LEDGER.md:211`). Abstain-always beat it on duplicate beads,
   .678 vs .370 (NE:5087-5089). A deterministic gate replaced a Jev pre-gate at 98.1% agreement with zero
   calls (`TESTS.md:282`).
2. **Typed models win where the label is visible in the text and lexical cues break.** Examples: injection on
   a public corpus (640/662 vs Haiku 584/662, `docs/LEDGER.md:113-115`), passage selection (FiQA top-1 76.2% vs
   BM25 39.3%, `README.md:95`), out-of-distribution spam (Jev .973 vs TF-IDF .725, `EVAL.md:1199`).
   Forecasting questions went 0 wins / 12 losses (`EVAL.md:3528`).
3. **Local open-weight models are not one thing.** On Banking77, Clef-Flash scores .962, Kev-4B .810 and Jev .787
   (`[RECOMPUTED]` from `work/local-decision-arms/rows-*.jsonl`; `README.md:132`). Kev-4B is near chance on
   vendored code (AUC .534, `[RECOMPUTED]`). Ollama nimble/tev1 lose to Jev on gate, injection and verify, but
   tev1 led Jev on SST-5 scoring in an EXPLORED run (.594 vs .546, p=.024, `work/jev-uhc5/receipt.json`).
4. **Calibration changes verdicts more than model choice does.** With the same dev-fitted Platt map on both
   arms, the Clef-vs-Jev calibration "win" on Banking77 disappears (ECE .0246 vs .0276, CI [-.010, +.037]).
   The vendored-code AUC gap is not significant (.839 vs .827, DeLong p=.67)
   (`work/plan-20261004/specs/advanced-mathops.md:7-8`).
5. **The classic encoder family is the biggest unmeasured gap.** We have never run a fine-tuned small encoder,
   SetFit, an NLI cross-encoder, an open injection guard model or a fact-check model like MiniCheck on our rows.
   The literature says these are the strongest per-dollar options when labels exist
   ([arXiv:2406.08660](https://arxiv.org/abs/2406.08660),
   [arXiv:2404.10774](https://arxiv.org/abs/2404.10774)). Four of the top 8 experiments below (X1, X3, X4, X6)
   fill this gap with labels we already hold.

## 5. Honest boundaries

- **One corpus per claim, mostly public.** Route rests on Banking77 (+ CLINC150 for Jev). Verify rests on
  SciFact/FEVER. Screen rests on one public attack corpus planted at three positions (`README.md:98`). Diff rests
  on one 320-window set we built (`work/vendor-paste/sample.json`). A win on one dataset does not carry: a
  routing threshold moved .67 → .37 between datasets and the decision flipped (`docs/LEDGER.md:212`).
- **Small n where it matters most.** Idle watcher 10 + 10 (`EVAL.md:3370`). Needs-human enrichment n=1
  (NE:4859). Coverage gap 11 rows. Gate harm rows 47 (`README.md:99`). Relevant memories dropped 1/6. Clef is
  measured on 2 tasks (`PRODUCT.md:172`). Review-finding novelty 23 provisional rows.
- **Model-model and process-derived labels.** Bead-judgment labels are reviewer-agent labels, not blind human
  labels (†`var/agent-tmp/dogfood/beadpass/PREREG.md`). Conductor-triage labels come from the conductor's next
  action (NE:4909). Review-novelty labels are one subagent's reading (`lit-judges.md:339`†). Agreement is not
  accuracy: Dawid–Skene over our four arms ranked them backwards, because their errors correlate (P(both wrong)
  .182 vs .059 under independence, `advanced-literature.md:26`).
- **Unequal treatment inflated one published comparison.** The Clef calibration win came from Platt on one arm
  only (`advanced-mathops.md:7`; the README line at `README.md:132` still states it). Every A/B bar needs equal
  recalibration and a paired test.
- **Run-to-run variance and multiplicity.** Two runs of the pinned model differ at p=.0076 on 3,080 rows
  (`advanced-literature.md:28`). 74 preregistered bars at α=.05 imply ~3.7 false passes (`advanced-mathops.md:35`).
- **EXPLORED is not a claim.** The local-model receipt's preflight was committed after its run
  (`work/jev-uhc5/receipt.json`, `provenance`), so tev1's Score lead is a hypothesis for X5.
- **Contamination risk (INFERENCE).** Public benchmarks may be in Clef's, MiniCheck's or encoders' training data.
  Clef's vendor blog uses Banking77 as a headline benchmark. Our own-traffic sets (tool results, fleet commands,
  vendored windows) are the stronger tests.
- **Prevalence is mostly unknown.** Lab rates do not transfer to organic traffic. Injection PPV is .35 at 1%
  prevalence (`advanced-mathops.md:38`). The skill veto fell from .990 to .335 on organic loads (`README.md:128`).
- **Usage is not benefit.** Smart stop ran ~4,000 calls / 7 d with 0 continuations observed (`PRODUCT.md:63`).
  Auto-thinking ran 3,806 calls / 7 d with no outcome measured (`classifier-areas.md:41`).
- **Latency figures come from one shared Mac under load** (`work/jev-uhc5/receipt.json`, `boundaries`). They are
  not SLOs. Vendor-hosted Clef (38.8 ms) and Jev (524.1 ms) medians are vendor-measured.
- **Provisional cascade number.** The 133/135 free-clear figure conflicts with a jev-nr3c row (42 scored /
  3 cleared), and its verifier resolution is outstanding (`PRODUCT.md:57`).
- **Scratch sources.** Every `†` citation, plus the prompt-library coverage v1 and the bead-judgment receipt
  (kept in the omp-kit tracker repo), must be committed as a receipt here before the README cites the number.
- **External evidence** is from abstracts unless a table is named. The only Jev/Clef head-to-head outside this
  repo is vendor-measured (`lit-judges.md:89-98`†).
